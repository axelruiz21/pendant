# PENDANT FMEA — Failure Modes and Effects Analysis

Status: living document. Seeded per Part V of `CLAUDE.md`; every newly
identified risk gets a row and, where applicable, a control implemented
in code. Scoring: Severity (S), Occurrence (O), Detection (D) each
1–10; RPN = S x O x D. D is scored *before* the listed controls, so
RPN reflects the unmitigated risk; the controls column records what
we did about it.
